# G3 Architect

A responsive architecture website built with React and Vite.

## Features

- Responsive navigation bar
- Hero section with banner image
- Team introduction
- Architecture features section
- Project statistics
- Sponsor section
- Responsive footer

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- Lucide React

## Installation

Clone the repository:

```bash
git clone https://github.com/pranto-codes/architecture-file.git
```

Navigate to the project directory:

```bash
cd architecture-file
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
Live link : https://architecture-file-z4ne.vercel.app/
